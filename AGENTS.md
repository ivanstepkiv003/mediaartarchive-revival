# Repository instructions for AI agents

Before changing the public frontend, read and follow
[`docs/design-guidelines.md`](docs/design-guidelines.md). It is the canonical
source for the project's information-first visual direction. Do not introduce
a promotional hero, oversized typography, decorative card system, or a second
competing design language without an explicit request and a corresponding
documentation update.

General project documentation starts at [`docs/README.md`](docs/README.md).
